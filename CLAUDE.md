# FormatWheel iOS — project rules

Native iOS / iPadOS port of the macOS menu-bar app **FormatWheel 格式轮盘**
(https://github.com/Elise616/FormatWheel, MIT). Open source; installed by sideloading
(AltStore / SideStore with a free Apple ID, TrollStore, or building with Xcode). No paid developer account.

**Prime directive: keep every feature.** Anything that cannot be ported 1:1 gets an equivalent and a ⚠️ row
in `docs/PARITY.md` explaining the difference. Never silently drop a feature.

## Fixed technical decisions (ask the user before changing any of these)

1. Native Swift. SwiftUI for app UI; the wheel's drawing and gestures are UIKit `UIView` + CoreGraphics
   (ported from upstream AppKit drawing code). iOS / iPadOS **17.0+**, Universal. Swift 6 toolchain,
   **Swift 5 language mode**, async/await.
2. Xcode project is generated by **XcodeGen** from `project.yml`. `*.xcodeproj` is never committed.
3. Layout:
   - `App/` — iOS app target (import, wheel, HUD, settings, App Intents, resources).
   - `Packages/FormatWheelCore/` — Catalog, Engine, all Ops, Privacy, FFmpegRunner, Zip, Output.
     **Must not import UIKit / AppKit / SwiftUI.** UI capabilities (pasteboard, WKWebView, print layout,
     rich-text codecs) are protocols the app injects (`Platform`).
   - `Packages/FormatWheelArt/` — Glyphs, Weapons, Drawing, Theme, SFX (CoreGraphics + AVAudioEngine only).
   - `upstream/` — read-only copy of upstream (`upstream/UPSTREAM.md` has the SHA). **Never modify.**
   - `scripts/`, `.github/workflows/`, `site/altstore/`, `docs/`, `Tests/`.
4. Distribution: GitHub Actions macOS runner builds with `CODE_SIGNING_ALLOWED=NO` → unsigned `.ipa`
   (ldid embeds entitlements) → `.tipa` for TrollStore → GitHub Releases → AltStore/SideStore source JSON
   on GitHub Pages.
5. FFmpeg: no `Process` on iOS and FFmpegKit is retired, so FFmpeg is **built from source in CI**
   (`scripts/build-ffmpeg.sh`, `.github/workflows/ffmpeg.yml`) into `FWFFmpeg.xcframework` (dynamic) and
   called in-process (`FFmpegRunner`). LGPL only (never `--enable-gpl`/`--enable-nonfree`); fftools never
   call `exit()`; progress, cancel, one session at a time. Includes libmp3lame, libopus, libvpx, libwebp,
   SVT-AV1, VideoToolbox, loudnorm/palettegen/atempo/setpts. Prebuilt artifacts live in the GitHub Release
   `ffmpeg-v<version>`; normal CI only downloads them (`scripts/fetch-ffmpeg.sh`). See `docs/FFMPEG.md`.
6. Dependencies must be MIT-compatible: ZIPFoundation (MIT), libwebp (BSD), FFmpeg (LGPL, dynamic),
   libmp3lame (LGPL), libopus / libvpx / SVT-AV1 (BSD). **Forbidden: x264, x265, fdk-aac or any GPL /
   non-free component.** Every new dependency → update `THIRD_PARTY_NOTICES.md` in the same commit.
7. No network, no data collection, no analytics or ad SDKs (FFmpeg is built with `--disable-network`).
8. Localisation with String Catalogs: **zh-Hans = upstream's original text** (also the source language and
   the lookup key), zh-Hant (Taiwan wording), en; follows the system language. Code identifiers and comments
   in English; README and user docs in Traditional Chinese.
9. Bundle ID `io.github.1cscar.formatwheel` (user-approved; the original `YOUR_GITHUB_USERNAME` placeholder had underscores, which bundle IDs reject) in `project.yml`; README explains
   what to change.

## Porting rules (macOS → iOS)

| Upstream | iOS replacement |
|---|---|
| `Shell.run` / `Process` | never; use `FFmpegRunner` or Swift/C libraries |
| ffmpeg (AVIF, WebM, MP3, Opus, speed, loudness, GIF palette) | bundled FFmpeg, upstream argument strings unchanged |
| ffprobe (privacy tags, duration, bit rate) | `FFmpegRunner.probe` (libavformat) |
| cwebp | libwebp (`-q`, `-mt`, keep ICC) |
| AVIF encode | `CGImageDestinationCopyTypeIdentifiers()` contains `public.avif` → ImageIO, else FFmpeg |
| textutil | own DocxReader/DocxWriter, ODTReader/ODTWriter (ZIP + XML: paragraphs, headings, bold/italic/underline, lists, links, basic tables, inline images); legacy `.doc` read via off-screen WKWebView (app-injected); `.doc` write = RTF content with `.doc` extension (⚠️); `doc.to.pdf` via UIMarkupTextPrintFormatter + UIPrintPageRenderer, A4 pages |
| afconvert | AVAssetReader/Writer, ExtAudioFile (AAC/ALAC/WAV/AIFF/FLAC); FLAC encoder detected at runtime, else FFmpeg's `flac` |
| ditto / zip / unzip | ZIPFoundation |
| NSPasteboard | UIPasteboard (injected) |
| NSWorkspace icons / reveal in Finder | QLThumbnailGenerator / "Show in Files" (`shareddocuments://`) / share sheet |
| Launch at login (ServiceManagement) | not applicable → "Haptics" toggle (⚠️) |
| Output next to the source | default `Documents/FormatWheel/` (`UIFileSharingEnabled` + `LSSupportsOpeningDocumentsInPlace`); optional output folder (security-scoped bookmark); optional auto-save images/videos to Photos; share after every run |
| Command-line mode | App Intents / Shortcuts ("list actions", "run action on files", "scan privacy"); glyph/weapon/sound export → hidden developer menu (ZIP); `--snapshot` → XCTest snapshot tests |
| Long jobs | `beginBackgroundTask`; `BGContinuedProcessingTask` on iOS 26+ |
| Cutout / OCR | Vision `VNGenerateForegroundInstanceMaskRequest` / `VNRecognizeTextRequest` (zh-Hans, zh-Hant, en) |
| `gen.path` | copy the Files-app location / file URL (⚠️) |
| libx264 in upstream ffmpeg args | `h264_videotoolbox` (x264 is GPL, forbidden) (⚠️): `-crf` → `-q:v` (`round(108 − 2.14·crf)`: 20→65, 27→50); if the device rejects `-q:v`, `-b:v` from the source bitrate (rules in PARITY.md §5); drop `-preset` |
| QuartzFilter "Gray Tone" (`pdf.mono`) | grayscale raster per page (setting 150/200/300 dpi, default 200), same page size + rotation, invisible text layer (existing PDF text first, else the pdf.ocr Vision pipeline), streamed page by page (⚠️) |

ImageIO, PDFKit, CoreImage, AVFoundation, CryptoKit, UTType port directly. Keep every upstream
"no ffmpeg" fallback path (the runtime check is `Tools.ffmpegAvailable`, overridable in tests).

## Interaction design (iOS)

- Get files: Files picker (multi-select, folders), PHPicker (**`loadFileRepresentation`** to keep original
  HEIC + EXIF, or the wanted level breaks), drag & drop, paste, share sheet / "Open in…" (all upstream-readable
  types declared in `CFBundleDocumentTypes`).
- Open the wheel: long-press anywhere ~0.25 s, wheel centred on the finger. iPad hardware keyboard: hold
  Shift → opens at the pointer. Drag-and-drop hover opens it directly; lifting the finger runs the slot.
- Select: slide or flick toward a slot; entering a slot plays `tick` + `UISelectionFeedbackGenerator`;
  release runs; sliding back to the centre cancels.
- Page flip: two-finger tap or tapping the centre tab; iPad keyboard Tab (and Q/E); trackpad scroll.
- Running: progress + cancel; cancelling deletes partial output.
- Done: HUD pass/fail animation + banner ("old size → new size") with Share, Show in Files, Save to Photos.
- VoiceOver on → tappable list mode. Audio session `.ambient` (never interrupts the user's music).

## Working rules

- Upstream is the reference: read the matching file in `upstream/Sources/` before porting. Keep Catalog
  pages, slot order, `big/ammo/title/detail` text, traits/stats numbers, multi-file logic, output naming and
  conflict handling, ffmpeg arguments and note text (e.g. 「只取了前 30 秒」「截取了前 40 秒」) as close to
  verbatim as possible.
- Upstream's action list is `Catalog.allIDs` — **73 IDs** at the pinned commit (the brief said 75;
  the user confirmed 73).
- Each action has at least one test. Fixtures are generated in code (`Tests/CoreTests/Fixtures.swift`):
  JPEG with GPS + device-model EXIF, multi-page PDF with an author, 1 s sine audio, 2 s colour-block video with
  an audio track via AVAssetWriter, generated docx. No large binaries in the repo.
- Per group of work: tests → update `docs/PARITY.md` → commit (Conventional Commits, e.g.
  `feat(core): port pdf.split`) → push.
- Hardware-dependent tests (VideoToolbox encoders on the simulator): detect the capability first; if it is
  missing, `throw XCTSkip("<reason>")`. This is the only allowed kind of skip (user-approved 2026-11-17).
- CI failures: read with `gh run watch` / `gh run view --log-failed`, fix the root cause. **Never disable or
  skip tests.**
- Stop and ask the user for trade-offs: licensing, clearly degraded replacements, paid services.
- Phases P0…P6 (see `docs/IOS_PORT_PLAN.md`); after each phase is green in CI, report and wait for 「繼續」.

## Everyday commands

```bash
brew install xcodegen ldid            # once (plus cmake pkgconf nasm to build FFmpeg)
scripts/fetch-ffmpeg.sh               # prebuilt FFmpeg into Vendor/FFmpeg (or scripts/build-ffmpeg.sh)
xcodegen generate                     # FormatWheel.xcodeproj
scripts/test.sh                       # unit tests on a simulator
scripts/build-unsigned.sh             # dist/FormatWheel.ipa + .tipa
```

Phase report format: 1) done items (PARITY IDs) 2) new ⚠️ and why 3) CI run links 4) things the user must
decide or do.
